#  smutHub robots.txt — PUBLIC, full indexing.
#
#  Cloudflare's Managed robots.txt prepends the crawler groups ABOVE this
#  file in production: `User-agent: * / Allow: /` for search, plus its
#  AI-crawler Content-Signal directives (ai-train=no, etc.). To avoid a
#  second, duplicate `User-agent: *` group, this origin file declares NO
#  group of its own — it only points crawlers at the sitemap.
#
#  Admin tooling (/admin.html, /catalog-admin.html) is kept out of the index
#  via `X-Robots-Tag: noindex` response headers (see _headers), which is
#  stronger than a robots Disallow: Google fetches the page, sees the noindex,
#  and drops it — whereas a Disallow can leave a bare URL indexed.
